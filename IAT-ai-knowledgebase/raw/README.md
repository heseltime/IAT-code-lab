# raw/ — the sources

Put your sources here: notes, worksheets, articles saved as Markdown or text, transcripts, a dataset
description. The agent reads them, but **never changes them**. They are the evidence the wiki is built on.

Tips:

- Use simple file names: `2026-11-20-biology-cell-notes.md`, `history-ww1-worksheet.txt`.
- Markdown (`.md`) and plain text (`.txt`) work best. For a PDF or a web page, save the text as `.md` first
  (e.g. with the [Obsidian Web Clipper](https://obsidian.md/clipper)).
- Images go into `raw/assets/`.
- Don't put private information about other people here (phone numbers, addresses, grades).
